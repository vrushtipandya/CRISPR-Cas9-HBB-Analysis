# CRISPR-Cas9 Guide RNA Design and Off-Target Analysis for the HBB Gene

## Project Overview
This project focuses on the computational analysis of the human HBB (Hemoglobin Beta) gene for CRISPR-Cas9 genome editing. The project includes retrieval of the HBB gene sequence from NCBI, nucleotide composition analysis, GC content calculation, reverse complement generation, PAM site identification, and guide RNA selection using Python.

## Objectives
- Retrieve the HBB gene sequence from NCBI.
- Perform nucleotide composition analysis.
- Calculate GC content.
- Generate the reverse complement sequence.
- Identify NGG PAM sites.
- Design potential guide RNA sequences.

- HBB gene sequence retrieved successfully.
- Nucleotide composition analyzed.
- GC content calculated.
- Reverse complement generated.
- *52 PAM sites identified*.
- Potential guide RNA sequences selected.

## Future Scope
This project can be extended by performing advanced off-target analysis using tools such as CRISPOR or CHOPCHOP and validating guide RNA efficiency experimentally.
